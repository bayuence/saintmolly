## Overview

Saint Molly is an ultra-minimalist brand. This repository contains the Phase 1 pre-launch infrastructure designed for sub-second delivery, zero-bloat asset footprint, and high-contrast typographic identity.

## Visual Identity & Specifications

- **Background:** Pure Dark (`#000000`)
- **Aesthetic:** Ultra-Minimalist High-Contrast
- **Typography Matrix:**
  - *Pre-title:* `WELCOME` (`#A3A3A3`, tracking `0.45em`)
  - *Headline:* `SAINTMOLLY.COM` (`#FFFFFF`, responsive fluid scale)
  - *Status:* `COMING SOON` (`#737373`, tracking `0.55em`)
- **Primary Typefaces:** Syne, Cinzel, Oswald, Space Grotesk

## Architecture

- **Core:** React 18 / Vite
- **Styling Engine:** Tailwind CSS
- **Edge Deployment:** Vercel / Cloudflare Pages

## Roadmap

- **Phase 1 (Current):** Brand Teaser & Domain Validation
- **Phase 2:** Product Catalog, Slide-over Bag, Payment Gateway & Logistics Integration
